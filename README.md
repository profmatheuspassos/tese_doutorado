# Cidadania ativa e governança — site de divulgação

Site estático de divulgação da tese de doutorado "Cidadania Ativa e Governança sob a
perspectiva do Direito Eleitoral comparado" (Matheus Passos Silva, Faculdade de Direito da
Universidade de Lisboa, 2022). Não é a publicação da tese: é uma versão em linguagem
simples, fiel ao argumento original.

Projeto em construção. Estado, regras e próximo passo: ver `CLAUDE.md`.

As pastas `fonte/` (tese original em .docx) e `conteudo/` (conversão integral) não são
versionadas. Para recriar `conteudo/`, coloque o .docx em `fonte/` e rode:

```bash
bash scripts/converter.sh
```
